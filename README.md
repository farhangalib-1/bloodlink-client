# 🩸 BloodLink – Connecting Donors, Saving Lives

<img width="1890" height="736" alt="image" src="https://github.com/user-attachments/assets/6011bd14-92aa-4db9-82e9-6f4f316c6bad" />

BloodLink is a modern blood donation management platform designed to connect blood donors with people in need of blood. It aims to make blood donation easier, faster, and more accessible by bringing donors and recipients together through a single platform.

> **Every Drop Counts, Every Life Matters. ❤️**

---

## 🚀 Technologies Used

### 🎨 Frontend
- **Next.js** – React framework for building the user interface.
- **Tailwind CSS** – Utility-first CSS framework for styling.
- **Hero UI** – Modern and reusable UI components.
- **Lucide Icons** – Beautiful and consistent icons.

### ⚙️ Backend
- **Node.js** – JavaScript runtime environment.
- **Express.js** – Backend framework for building REST APIs.
- **MongoDB** – NoSQL database for storing application data.

### 🔐 Authentication
- **Better Auth** – Authentication and user session management.

### 💳 Payment Integration
- **Stripe** – Secure online payment processing.

---

## ✨ Key Features

- **User Authentication:** Secure user registration, login, and session management.
- **Donor Management:** Manage donor information and profiles.
- **Blood Donation Requests:** Connect blood donors with people who need blood.
- **Blog Section:** Share blood donation awareness articles and information.
- **Role-Based Access Control:** Different access permissions for users and administrators.
- **Admin Dashboard:** Manage users, donors, and platform activities.
- **Payment Integration:** Accept online payments through Stripe.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
